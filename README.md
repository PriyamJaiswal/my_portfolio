# 🚀 Priyam Jaiswal - Personal Developer Portfolio

A modern, responsive, and interactive personal developer portfolio website designed with a sleek dark aesthetic, golden accents, and micro-interactions.

Live Demo & Preview: [Priyam Jaiswal Portfolio](https://github.com/PriyamJaiswal/vvv)

---

## 🌟 Features

- **About**: Profile introduction, specialized domains (Java, Spring Boot, Microservices, Full-Stack, Databases, Cloud & DevOps), and interactive tech stack grid.
- **Resume**: Education history, practical experience, and interactive skill proficiency meters.
- **Projects**: Real-world projects showcase (UPI Offline Mesh, Blog Platform API, ShopElite E-Commerce, Velora Hotel Booking) with live GitHub repo links and tech badges.
- **Certificates**: Dedicated certification credentials section with full-screen interactive preview modals and direct verification links.
- **Contact**: Functional email contact form powered by FormSubmit, direct WhatsApp link, direct mailto integration, and location map.
- **Responsive Design**: Fully responsive across mobile, tablet, and desktop viewports.

---

## 🛠️ Built With

- **HTML5 & Semantic Structure**
- **Vanilla CSS3** (Custom Properties, Flexbox, Grid, Glassmorphism, Animations)
- **Vanilla JavaScript (ES6+)**
- **Ionicons** (Vector Icons)
- **FormSubmit API** (Backend-less Email Delivery)

## 🚀 Quick Start Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/PriyamJaiswal/vvv.git
   cd vvv
   ```

2. Open `index.html` in your browser or run a simple local server:
   ```bash
   python3 -m http.server 8080
   ```

3. Visit `http://localhost:8080` in your web browser.
